TinkerBox
Version 1.0.0
Created by Loyftwa

TinkerBox ist eine modulare Werkzeugkiste für World of Warcraft Retail / Midnight.
Das Addon bündelt mehrere praktische Funktionen für Farming, Crafting,
Goldverwaltung und persönliche Organisation in einer einheitlichen Oberfläche.

FEATURES

- FarmTracker
  Farming-Sessions, Kills, Drops, Wunsch-Items, Favoriten und Verlauf.

- CraftingList
  Ausgewählte Rezepte übernehmen, benötigte Materialien erfassen,
  Mengen verwalten und eine Einkaufsliste anzeigen.

- GoldKasse
  Aktuelles Gold, Einnahmen, Ausgaben, Tagesbilanz,
  Gold-Sessions und Verlauf.

- Zusatzinfos
  Gesamt-Gold und Charakterübersicht für bekannte Charaktere
  auf dem aktuellen Realm.

- TinkerNotes
  Mehrere Notizen mit Titel und Text speichern, öffnen und verwalten.

- Minimap-Button
  Schneller Zugriff auf TinkerBox direkt über die Minimap.

- Einstellungen
  Minimap-Button, Fenster-Fixierung, UI-Skalierung,
  Chat-Benachrichtigungen, Verlaufs-Limit und Daten-Reset.

INSTALLATION

1. Die ZIP-Datei entpacken.
2. Den Ordner "TinkerBox" nach folgendem Verzeichnis kopieren:

   World of Warcraft\_retail_\Interface\AddOns\

3. World of Warcraft starten oder /reload verwenden.
4. TinkerBox über den Minimap-Button öffnen.
