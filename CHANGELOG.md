# Changelog

## 1.0.0

Initial public release.

### Added

- Complete themed TinkerBox main interface
- FarmTracker with sessions, favorites and history
- CraftingList with recipe tracking and shopping list
- Crafting favorites
- GoldKasse with daily tracking, sessions and history
- Zusatzinfos with total-gold and character overview
- Class-colored character names
- Fixed gold / silver / copper display columns
- TinkerNotes with multiple saved notes
- Custom minimap button and tooltip
- Settings for UI, window locking, history and reset
